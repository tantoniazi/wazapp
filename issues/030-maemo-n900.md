# 030 — Maemo: porta para o Nokia N900 (Fremantle)

**Labels:** `epic/maemo`, `fase-4`

## Objetivo
Levar o cliente nativo para o N900: Qt 4.6, 256 MB RAM.

## Critérios de aceite
- [ ] UI QML adaptada ao Fremantle (recurso/temas GTK-QT legados)
- [ ] `wazapp-core` (armv7 musl, rustls) roda no device dentro do orçamento de RAM
- [ ] `.deb` Fremantle assinado e instalável no N900
- [ ] Teste de bateria: sessão ativa sem drenar bateria em 2 h de uso leve
